# R Programming and Statistical Learning — Foundations

**R · RStudio · R Markdown · Descriptive Statistics**

[← Academic portfolio](../ACADEMIC_PORTFOLIO.md)

An introductory learning collection documenting R scripts, R Markdown reporting and work with built-in datasets.

## Topics practiced

- Creating variables, vectors and sequences.
- Selecting vector elements by position or condition.
- Sorting values and evaluating arithmetic expressions.
- Using built-in data such as `mtcars`, `cars` and `pressure`.
- Calculating descriptive statistics and creating simple plots.
- Generating reports using R Markdown.

## Example: `mtcars` fuel-economy summary

One tutorial produced these values from `mtcars$mpg`:

| Statistic | Reported value |
| --- | ---: |
| Mean miles per gallon | 20.09062 |
| Standard deviation | 6.026948 |

Another R Markdown tutorial included a pressure-versus-temperature plot using R's built-in `pressure` dataset.

## What I learned

R's vector operations provide concise ways to inspect small datasets, while R Markdown keeps code, output and explanations together in a reproducible report.

This is **foundational R coursework**, not a machine-learning model or advanced statistical study. More substantial analysis projects can be added as the coursework progresses.
